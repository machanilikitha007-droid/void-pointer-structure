# Void Pointer with Structure Data

## Author
M.Likitha

## Description
This program demonstrates how a void pointer can receive
the address of a structure.

Inside the function, the void pointer is converted into
a structure pointer before accessing the structure members.

## Concepts Used
- Void pointer
- Structure
- Structure pointer
- Type casting
- Function with pointer parameter
- Structure member access

## How to Run

gcc void_pointer_structure.c -o void_pointer_structure

./void_pointer_structure
